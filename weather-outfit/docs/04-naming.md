# 04. 앱 이름 후보

> 컨셉: "날씨를 보면, 오늘 우리 가족이 입을 옷까지 알려주는 앱". 패션 앱이 아니라 **생활·날씨 앱**으로 느껴져야 하고, 가족(아이·부모님)을 챙기는 따뜻함이 있어야 한다.
> 아래는 후보일 뿐이며, 확정 전에 **특허정보검색서비스(KIPRIS, kipris.or.kr)** 상표 검색과 앱스토어·플레이스토어 검색으로 중복을 확인해야 한다. (2026-10-21 기준 조사 범위에서 동일 이름의 유명 앱은 확인되지 않았으나, 소규모 앱·상표는 검색 필요)

## 추천 후보 (우선순위 순)

| 이름 | 영문/표기 | 뜻·느낌 | 장점 | 유의점 |
|---|---|---|---|---|
| **옷날씨** | Otnalssi / OTNALSSI | "옷 + 날씨". 날씨를 보면 옷이 정해진다 | 두 글자 조합이라 짧고 직관적. 검색어 "옷 날씨"와 자연스럽게 겹쳐 검색 유입에 유리 | 일반명사 조합이라 상표 등록이 까다로울 수 있음 (도형과 함께 등록 권장) |
| **입을날씨** | Ipeul-nalssi | "오늘 입을 날씨" — 날씨가 곧 입을 옷 | 동사(입다)가 들어가 행동이 떠오름. 패션 느낌 없음 | 네 글자, 발음이 약간 길다 |
| **오늘입기** | Oneul Ipgi | "오늘 입기" — 아침에 여는 앱이라는 사용 맥락 | 아침 루틴 앱 느낌, 알림 문구("오늘입기 알림")와 잘 어울림 | "입기"가 다소 평범 |
| **포근** | Pogeun | 따뜻하고 편안함 | 두 글자, 감성적. 가족을 챙기는 느낌. 로고화 쉬움 | 날씨·옷이 바로 연상되지는 않아 부제가 필요 ("포근 — 우리 가족 날씨 옷차림") |
| **겹** | Gyeop / GYEOP | 옷을 겹쳐 입는 "겹" | 한 글자, 독특, 로고·아이콘 만들기 좋음. "오늘은 세 겹" 같은 표현을 UI에 쓸 수 있음 | 처음 보면 뜻을 설명해야 함 |
| **날씨옷** | Nalssi-ot | 날씨에 맞는 옷 | 가장 설명적 | "날씨옷장"(타사 기능명)과 혼동 가능 |
| **우리집 옷날씨** | (현재 가칭) | 가족 단위 강조 | 컨셉이 그대로 드러남 | 다섯 글자+띄어쓰기로 길다. 아이콘 아래 이름이 잘릴 수 있음 |
| **오늘 뭐 입지** | Oneul Mwo Ipji | 매일 아침 하는 말 그대로 | 공감대가 큼, 검색어와 일치 | 이미 비슷한 이름의 콘텐츠·서비스가 많아 상표·검색 변별력 낮음 |

## 영문 보조 이름 (스토어 영문명·도메인용)

| 영문 | 설명 |
|---|---|
| **Layerly** | layer(겹) + ly. 겹쳐 입기 컨셉 — 해외 유사 앱 존재 가능성 확인 필요 |
| **WearCast** | wear + forecast. "옷 예보" |
| **Dressy Weather** | 발음 쉬움, 다소 패션 느낌 |
| **OTNALSSI** | 한글 이름 그대로 로마자 표기 (브랜드 일관성) |

## 추천 조합

1. **옷날씨** (메인) + 부제 "오늘 우리 가족 뭐 입지" — 짧고 직관적이며, 앱 안에서 쓰는 말("옷차림")과도 통한다.
2. **포근** (메인) + 부제 "우리 가족 날씨 옷차림" — 감성 브랜드로 키우고 싶을 때.
3. **겹** (메인) + 부제 "날씨 맞춤 겹쳐 입기" — 독특한 브랜드를 원할 때.

## 이름을 정한 뒤 바꿀 곳

- `app/app.json` → `expo.name` (앱 아이콘 아래 이름), `expo.slug`
- `app/src/lib/brand.ts` → `APP_NAME` 기본값
- `server/package.json`, `admin/index.html`(관리자 제목), `README.md`, `docs/`
- 앱 아이콘·스플래시 이미지 (`app/assets`)
