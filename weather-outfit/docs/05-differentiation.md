# 05. 경쟁 앱과 차별화 포인트

> "날씨 + 체감온도별 옷차림 추천"은 이미 있는 기능이다 (웨더핏, weather2wear, 날씨돌 등).
> 우리 앱은 그 **기본을 모두 갖춘 위에** 아래 엣지를 더한다. 이 문서는 기획 기준이자 체크리스트다.

## 1. 기본으로 갖춰야 할 것 (경쟁 앱 수준)

| 항목 | 상태 | 비고 |
|---|---|---|
| 현재 기온·체감·최저/최고·하늘 | ✅ | 기상청 실시간 |
| 시간별 예보 (강수확률 포함) | ✅ | 등원·하원·퇴근 시간 표시 |
| 미세먼지·초미세먼지·자외선 | ✅ | 에어코리아·기상청 생활기상지수 |
| 체감온도별 옷차림 추천 | ✅ | 8단계 기온 구간 + 개인 보정 |
| 살아 움직이는 날씨 장면 (삼성·애플 날씨처럼) | ✅ | 도형·애니메이션으로 직접 그림. 이미지 저작권 문제 없음 |
| 주간 예보 | ⏳ | 중기예보 키 승인됨, 다음 단계 |
| 위젯·알림 | ⏳ | 설정 화면만 준비됨 |

## 2. 엣지 포인트 (우리만의 것)

### ① 가족 전체를 한 화면에 — "엄마 코트, 아이 장화, 아기 내복"
경쟁 앱은 1인용이거나 남/여/아기 **구분 선택**(웨더핏)에 그친다. 우리는 **가족 구성원을 등록**하고 나이·체형·추위/더위 민감도·건강 상태(천식·아토피 등)를 각각 반영해 **한 화면에서 모두** 보여준다. 아침에 아이와 부모님 옷을 챙기는 사람이 핵심 사용자.

### ② 하루 옷차림 흐름 — 아침·낮·저녁이 다르다 (구현 완료)
일교차가 큰 날 "지금 기온"만 보고 입으면 낮에 덥거나 저녁에 춥다. **아침 8시 → 낮 2시 → 저녁 6시** 시간대별 기온과 옷 두께를 한 줄로 보여주고, 차이가 나면 "겉옷을 챙기세요"라고 바로 말해준다. 경쟁 앱에는 없는 표현 방식.

### ③ 왜 이렇게 추천했는지 보여준다
"추위를 잘 타서 2℃ 더 춥게 계산했어요", "65세 이상은 한 단계 따뜻하게" — 추천 근거를 그대로 노출. 신뢰와 재방문의 핵심.

### ④ 건강 민감군 보정
미세먼지 "보통"이어도 호흡기 질환·영아·고령자는 **민감군 기준**으로 마스크·외출 자제를 안내. 24개월 미만은 마스크 대신 외출 줄이기. 폭염·한파 기준도 민감군은 더 보수적으로.

### ⑤ 개인 체감 학습 (다음 단계)
저녁에 "오늘 추웠어요 / 딱 좋았어요 / 더웠어요" 한 번 누르면 구성원별 보정값이 조금씩 조정된다. 쓸수록 정확해지는 앱.

### ⑥ 챙길 것 체크리스트 → 쇼핑 (다음 단계)
우산·마스크·선크림·목도리 같은 "챙길 것"이 가족별로 정리되고, 없는 것은 바로 살 수 있게 연결. 추천 아이템마다 표준 카테고리 키가 붙어 있어 커머스 연동이 쉽다.

## 3. 참고한 경쟁 앱 (간단 메모)

| 앱 | 하는 것 | 우리와 다른 점 |
|---|---|---|
| **웨더핏 (날씨별 옷차림)** — Google Play, unpredicted | 체감온도별 옷 추천, 남/여/아기·실내/실외/운동 설정 | 사용자 1명 기준 설정. 가족 구성원 개념 없음. 광고 포함 |
| **weather2wear** | 날씨에 맞는 옷 추천 (해외) | 1인용. 한국 공공데이터·미세먼지 반영 없음 (상세 **확인 필요**) |
| **날씨돌 (날씨옷장)** | 체감온도 옷차림 + 입은 옷 기록 | 1인 기록 기반. 가족·건강 보정 없음 |
| **삼성 날씨 / 애플 날씨** | 몰입형 날씨 장면, 시간별·주간, 지도 | 옷차림 추천 없음. **UI를 똑같이 베끼지 않도록** 주의: 장면은 우리가 도형으로 직접 그린 것, 구성(큰 기온 + 장면 배경)은 일반적인 날씨 앱 관습 |

## 4. 저작권·표절 주의 (장면 디자인)
- 사진·일러스트 이미지를 **쓰지 않는다**. 해·달·구름·비·눈은 전부 코드로 그린 도형 + 애니메이션.
- 삼성·애플 날씨의 **구체적인 그래픽 요소**(아이콘 세트, 배경 사진, 레이아웃 비율)를 복제하지 않는다. "배경 장면 위에 큰 기온 숫자"는 업계 공통 표현.
- 앱 이름·아이콘·색은 독자적으로 만든다. 아이콘은 추후 디자이너 작업 시 상표 검색 병행.
