## PC에서 실행하는 법 (매번)

터미널 2개를 `~/Downloads/JSL/weather-outfit` 에서 엽니다.

```bash
# 터미널 ① 서버
npm run dev:server        # "공공데이터 키 있음 → 실제 날씨" 가 나와야 정상

# 터미널 ② 앱 미리보기
npm run preview:live      # 브라우저에서 http://localhost:8090/frame
```

Claude가 수정해서 PR을 합친 뒤에는:
```bash
npm run update            # 최신 코드 받기 + 패키지 설치
```
그다음 터미널 ②에서 Ctrl+C → `npm run preview:live` 다시 실행.

주의: 서버는 한 번에 하나만. "address already in use :4000" 오류가 나면 `lsof -ti :4000 | xargs kill` 로 이전 서버를 끕니다.

## 설계 요약

- **로그인 없이** 날씨·미세먼지·자외선·시간별 예보를 볼 수 있다.
- **코디 추천은 로그인 후**: 키·몸무게·체형·온도감(추위/더위)을 입력받아(동의 필수) 개인 체감온도를 계산한다. 가족 구성원도 추가할 수 있다.
- **추천 엔진**: 기상청 체감온도 공식 + 나이·민감도·체형(BMI)·건강 상태·활동량 보정 → 옷 두께 5단계 + 겉옷/상의/하의/신발/챙길 것 + 주의사항 + 추천 이유.
- **데이터**: 기상청 단기예보(기온·시간별), 기상청 생활기상지수 V5(자외선), 에어코리아(미세먼지). 키가 없으면 데모 데이터.
- **소셜 로그인은 서버가 대행**: 앱에 비밀키가 들어가지 않고 Expo Go에서도 동작. 지금은 "개발용 테스트 로그인"으로 대체(출시 버전에서 자동 제거).
- **개인정보**: 본인 프로필은 서버 저장(동의 후), 가족·건강 정보는 기기에만 저장.
- **설정 파일 우선순위**: `.env` → `env.local.txt`(내 키) → `env.txt`(저장소 기본값).

## 알아둘 것 / 주의

- `server/env.txt`는 저장소 기본값이니 직접 고치지 않는다. 내 키는 `server/env.local.txt`.
- 인증키가 적힌 캡처·메모는 외부에 공유하지 않는다. 유출이 의심되면 공공데이터포털에서 **인증키 재발급** 후 `env.local.txt`만 바꾼다.
- 공공데이터 개발계정은 서비스당 하루 1만 건. 사용자가 늘면 운영계정 전환 신청(무료).
- 사용 로그는 `server/data/app.db`의 `events` 테이블에 쌓인다. 어떤 화면·버튼인지만 기록하고 이름·키·몸무게 같은 개인정보는 넣지 않는다.
- 터미널의 `26 vulnerabilities` 경고는 개발 도구 보안 알림으로 지금은 무시. 출시 전 정리 예정.
